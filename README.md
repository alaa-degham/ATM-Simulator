ATM Simulator (Java)

A console-based ATM simulation application written in Java.

Features:
- PIN Authentication: Validates a 4-digit PIN with up to 3 attempts before locking the account.
- Check Balance: Displays the current account balance.
- Deposit: Adds valid positive amounts to the balance and updates successful transaction count.
- Withdraw: Checks for valid amounts and sufficient balance before deducting funds.
- Account Status: Categorizes the account status (VIP Customer, Regular Customer, or Low Balance) based on the current balance.

Technologies Used:
- Java (Scanner for user input, loops, conditionals, and switch statements)
